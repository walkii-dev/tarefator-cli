# Tarefator-cli

O Tarefator-cli é uma aplicação simples baseado no projeto "TaskTracker CLI" 
sugerido pela aba de projetos do site https://roadmap.sh para projetos backend.

A idéia deste projeto é uma simples aplicação de linha de comando (utilizando a
linguagem java) para criar e gerenciar tarefas.

## Tecnologias usadas:
- Java 21(Eclipse Temurin)
- Docker (em desenvolvimento)
